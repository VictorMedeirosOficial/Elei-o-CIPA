PASSO A PASSO — VOTAÇÃO CIPA 2026/2027 (GITHUB + PLANILHA GOOGLE)

1. CRIAR A PLANILHA GOOGLE E O APPS SCRIPT
   - Crie uma nova Planilha no Google Sheets (ex.: "Votação CIPA 2027 - Policlínica").
   - No menu superior, clique em: Extensões > Apps Script.
   - Apague o código padrão e cole todo o conteúdo do arquivo "apps_script.gs".
   - Clique em Salvar (ícone de disquete).

2. PUBLICAR COMO APP DA WEB
   - No Apps Script, clique em: Implantar > Nova implantação.
   - Tipo: App da Web.
   - Executar como: Eu (seu e-mail).
   - Quem pode acessar: Qualquer pessoa.
   - Clique em Implantar, autorize as permissões e COPIE a URL gerada (termina em /exec).

3. CONECTAR NA INTERFACE
   - Abra o arquivo "script.js".
   - Na linha 6, cole a URL copiada dentro das aspas de:
     const APPS_SCRIPT_URL = 'SUA_URL_AQUI';

4. SUBIR PARA O GITHUB PAGES
   - Suba para o seu repositório no GitHub:
     * index.html
     * style.css
     * script.js
     * pasta assets/ (com as logos e fotos)
   - Ative o GitHub Pages em Settings > Pages > Branch main.
   - Pronto! Os votos cairão em tempo real na sua planilha e na aba Apuração do site.
